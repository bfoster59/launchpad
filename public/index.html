⚙️ Settings

All values are stored locally in SQLite — no cloud sync. Edits apply immediately and persist across server restarts.

GitHub Personal Access Token

Required for private-repo imports, bulk import from your account, and sync status. Create one (scopes: repo)

Clone Base Directory

Where new clones land. Default /home/bfoster resolves to C:\home\bfoster\<project> on Windows, or /home/bfoster/<project> on Linux/macOS.

Default Terminal (Open Terminal button)

Which terminal launchpad opens when you click 💻 Open Terminal on a project. Choices depend on your OS.
